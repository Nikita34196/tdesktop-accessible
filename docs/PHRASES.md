# Словарь коротких фраз (Simple)

`CompactPhrase()` сокращает текст для NVDA:

- убирает лишние пробелы и повторы;
- заменяет длинные типы вложений на короткие («фото», «голосовое», «файл»);
- в списке чатов — имя + последнее сообщение в одной строке.

Примеры панелей (F6):

- «Список чатов»
- «Сообщения»
- «Поле ввода»

Тест при старте (**Ctrl+Shift+T**):

- «Режим простой озвучки Telegram загружен»

Новые фразы добавляйте в `telegram_simple_speech.h` и обновляйте этот файл.
