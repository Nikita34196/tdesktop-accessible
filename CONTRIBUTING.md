# Как внести вклад

Спасибо за интерес к проекту! Вот как можно помочь:

## Тестирование

Самое ценное — тестирование с реальным скринридером.

1. Скачайте сборку из [Releases](../../releases)
2. Запустите с NVDA / JAWS / Narrator
3. Проверьте: какие элементы озвучиваются? какие нет?
4. Создайте Issue с описанием: что не работает, что ожидалось

## Разработка

1. Форкните репозиторий
2. Внесите изменения в файлы `accessibility/`
3. Создайте Pull Request с описанием

### Что можно улучшить

- Озвучивание уведомлений о новых сообщениях
- Голосовые сообщения: пауза и перемотка с клавиатуры
- Чтение реакций и цепочек ответов
- Навигация по результатам поиска стрелками с озвучкой

## Отчёты об ошибках

Создайте Issue и укажите:
- Версию Telegram Accessible
- Версию NVDA / JAWS
- Версию Windows
- Шаги для воспроизведения
- Что произошло vs что ожидалось
