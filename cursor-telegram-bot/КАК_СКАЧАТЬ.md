# Как скачать папку на компьютер

## Способ 1 — архив (проще всего)

В облачной среде Cursor файл лежит здесь:

```
/workspace/cursor-telegram-bot.zip
```

**Скачать:**

1. В Cursor слева откройте **проводник файлов** (Explorer).
2. Поднимитесь в корень workspace → найдите **`cursor-telegram-bot.zip`**.
3. Правый клик → **Download** / **Скачать**.
4. Распакуйте на ПК, например в `C:\Projects\cursor-telegram-bot`.

## Способ 2 — папка целиком

В проводнике найдите папку **`cursor-telegram-bot`** (рядом с zip) → правый клик → скачать папку (если Cursor позволяет) или скачайте zip из способа 1.

## Способ 3 — GitHub

1. Создайте репозиторий: https://github.com/new → имя `cursor-bot` (пустой).
2. На ПК в PowerShell:

```powershell
cd C:\Projects
git clone https://github.com/Nikita34196/cursor-bot.git
```

3. Скопируйте в него файлы из распакованного zip и сделайте `git push`  
   (или попросите агента в Cursor: «запушь cursor-telegram-bot на GitHub»).

## После скачивания

1. **File → Open Folder** в Cursor → выбранная папка.
2. Откройте **`ДАЛЬШЕ.md`**.
