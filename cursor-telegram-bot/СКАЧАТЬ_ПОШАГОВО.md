# Скачать бота на компьютер — по шагам

## Способ 1. Прямая ссылка (самый простой)

1. Откройте в **обычном браузере** (Chrome, Edge) ссылку из сообщения агента.  
2. Файл `cursor-telegram-bot.zip` скачается сам.  
3. Щёлкните по zip **правой кнопкой** → **Извлечь всё**.  
4. Папка `cursor-telegram-bot` — это и есть бот.

---

## Способ 2. Через GitHub (если ссылка не открылась)

### Шаг 1 — создать пустой репозиторий

1. Откройте https://github.com/new  
2. Имя: `cursor-bot`  
3. **Не** ставьте галочки README / .gitignore  
4. **Create repository**

### Шаг 2 — на ПК в PowerShell

```powershell
cd $HOME\Downloads
git clone https://github.com/Nikita34196/cursor-bot.git
cd cursor-bot
```

### Шаг 3 — попросить агента залить файлы

В **этом** чате Cursor напишите:

```
Залей файлы из папки cursor-telegram-bot в https://github.com/Nikita34196/cursor-bot
```

После push снова на ПК:

```powershell
cd $HOME\Downloads\cursor-bot
git pull
```

---

## Способ 3. Скопировать вручную (если видите файлы слева)

1. В Cursor слева откройте **Explorer** (иконка двух листов).  
2. Найдите папку **`cursor-telegram-bot`**.  
3. Откройте файл **`bot.py`**.  
4. Если вверху файла есть **⋮** или **...** → ищите **Download**.  
5. Так по одному файлу долго — лучше способ 1 или 2.

---

## После скачивания

1. Cursor → **File → Open Folder**  
2. Выберите распакованную `cursor-telegram-bot`  
3. Откройте **`ДАЛЬШЕ.md`**
